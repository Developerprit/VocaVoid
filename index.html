VocaVoid 是一个带 Web 控制台 的 VF 音乐编辑器。在钢琴卷帘上作曲、为每个音符填词，选一声库，一键生成歌唱 WAV。VV + VF 同时运行，开箱即用。

// FEATURES · 功能特性
为创作而生的音乐编辑器
没有臃肿的菜单，没有学习曲线——把旋律画出来，让它唱出来。
01

钢琴卷帘编辑器

单击放置音符、拖拽移动、拖右缘改时长、双击编辑歌词。网格吸附，所见即所得。

Canvas piano-roll
02

逐音符歌词

每个音符自带音节，直接驱动 VocaForge 的歌唱合成，单曲也可成歌。

Per-note lyrics
03

一键合成

选好声库，点击合成——歌曲经 VocaForge 网关生成 WAV，存入 wav/。

One-click synth
04

声库管理

从 vfvp/ 载入真实声库，或直接使用内置 stub-zh 测试声库即时试听。

Voicebank picker
05

暗色合成器工作室

暗色为主、含浅色双主题，等宽字体与琥珀强调色，专业而不浮夸。

Dark synth studio
06

零重依赖

VV 后端纯标准库；VocaForge 的 stub 后端无需模型即可合成，开箱即跑。

Zero heavy deps
// ARCHITECTURE · 运行原理
VV 与 VF，并肩运行
启动器同时拉起两个进程：VocaVoid 控制台（VV）与 VocaForge 合成网关（VF），浏览器只与 VV 对话。

VocaVoid · VV

托管原生 Web 控制台，负责歌曲工程 CRUD、声库浏览与钢琴卷帘；合成请求以服务端对服务端方式代理出去。

synth ▸

VocaForge · VF

暴露 /api/v1 合成与声库注册接口，调用 DiffSinger 或 stub 后端，产出 16-bit PCM 歌唱 WAV。

Python 3.9+ VocaForge 0.4.2 Native Frontend stdlib http.server .vfvp voicebanks Canvas 2D
